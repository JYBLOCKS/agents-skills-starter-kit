# Project Context

## Purpose
This repository is a portable starter kit for agent-driven software delivery across Codex, Claude, and similar coding tools.

## Current Operating Model
- Flat `agents/*.md` and `skills/*.md` files are the canonical contracts.
- The orchestrator is the single entry point for user work.
- SDD is required before implementation.
- TDD and validation evidence are required before completion.
- Caveman mode is the default response style for progress and handoff summaries.

## Quality Bar
- Maintainable, reusable, documented, validated outputs.
- Smallest useful set of agents and skills per task.
- Explicit specs, context, risks, tests, and Definition of Done.
