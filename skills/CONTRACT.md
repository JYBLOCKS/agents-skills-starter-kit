# Skill Contract

Every skill must be a flat Markdown file under `skills/*.md`.

## Required Frontmatter
- `name`
- `type`
- `purpose`
- `when_to_use`
- `token_saving_level`

## Required Sections
- Purpose
- Use When
- Rules
- Process
- Output Format
- Quality Gates

Do not create per-skill folders.
