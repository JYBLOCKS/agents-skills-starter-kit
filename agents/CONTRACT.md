# Agent Contract

Every agent must be a flat Markdown file under `agents/*.md`.

## Required Frontmatter
- `name`
- `role`
- `seniority`
- `main_goal`
- `when_to_use`
- `delegates_to`
- `uses_skills`

## Required Sections
- Purpose
- Responsibilities
- Inputs Required
- Outputs
- Delegation Rules
- Skills Used
- Quality Gates
- Response Style

Do not create per-agent folders.
